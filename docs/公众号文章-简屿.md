# 我把 Mac 刘海改成了“简屿”：能刷抖音小窗，也能顺手干点正事

我一直觉得，Mac 顶部那块刘海多少有点浪费。

占着屏幕最显眼的位置，平时除了放摄像头，基本没什么存在感。于是这段时间，我在开源项目 TRAE FLOW 的基础上做了一次比较彻底的个人改造：换掉原来的产品逻辑，重新设计界面，把它改成了一个贴在 Mac 顶部的桌面工作台。

我给它取了一个更简洁的名字——**简屿**。

它看起来像个轻量的桌面工具，但实际用下来，干的事情还挺杂。你可以用它启动电脑里的 App、刷抖音、把视频缩成置顶小窗，也可以接入 AI Agent、管理需求文档、截图和查看监控提醒。

说白了，我想做的不是一个“老板看了很感动”的效率软件，而是一个自己每天真的愿意点开的东西。

## 先说怎么找到它

GitHub 项目地址：

**https://github.com/maomengen888-maker/trae-flow**

目前它还是一个持续迭代中的 macOS 项目，代码、说明和安装包会按版本逐步整理到仓库。如果你对这种“把 Mac 刘海变成桌面入口”的想法感兴趣，欢迎先收藏项目、点个 Star，也欢迎通过 Issue 告诉我你最想加什么功能。

简屿是在 [TRAE FLOW](https://github.com/ccsonicc333/trae-flow) 的开源基础上继续改造的。原项目更偏向 TRAE 任务状态和自定义灵动岛，我这个版本则把重点转向了日常桌面入口、内容消费和个人工作管理。

## 打开以后，先看到的是电脑里所有 App

简屿默认进入 **APP 管理**。

它会读取 Mac 已安装的应用，用网格方式集中展示。双击图标直接启动，长按可以隐藏不想展示的应用，不需要再进入一层“App 详情页”。

这不是什么惊天动地的功能，但用起来非常直接。我的想法就是：既然这个入口已经贴在屏幕顶部，那它最好真的能替代一部分 Launchpad 和 Dock，而不是再造一个只能看的展示页。

![简屿默认的 APP 管理界面](./wechat-assets/01-app-management.png)

底部还放了截图入口，支持区域、窗口和全屏截图，也可以通过快捷键直接唤起。截图完成后还可以固定置顶，拿来对照需求、参考设计或者临时抄一段信息都挺方便。

## 最“摸鱼”的功能，当然是抖音

接下来就是这个项目最不遮掩的一部分。

顶部有一个独立的 **抖音入口**，点击后直接在简屿窗口里打开桌面版抖音。不需要再切浏览器，也不用在一堆标签页里找刚才刷到哪里了。页面保留了搜索、分类和推荐内容，鼠标滚轮或触控板可以继续浏览。

![在简屿内直接打开抖音](./wechat-assets/02-douyin.png)

但只把网页塞进窗口里，还不够“摸鱼”。

所以我又给它加了一个 **小窗播放**。

点击以后，当前抖音页面会变成一个可以拖动的独立小窗，默认出现在桌面右侧并保持置顶。你可以一边看资料、一边写东西，旁边顺手挂着视频。窗口不抢主界面的空间，也不会被简屿自己的大面板盖住。

![抖音可移动、始终置顶的小窗模式](./wechat-assets/03-douyin-floating.png)

这部分前后改了好几轮。

我最开始试过模拟手机页面，结果直播和推荐流适配得很别扭，上下滑动也不顺。最后还是回到桌面版页面，让网站自己处理滚轮和触控板事件。小窗关闭时，视频和音频会一起暂停，不会出现窗口没了、老板走了、声音还在办公室里继续响的社死场面。

这个细节看起来小，真碰上一次就知道有多重要。

## 摸鱼归摸鱼，Agent 也得能干活

简屿右上角还有一个 **AI 入口**。

我不想简单放一个跳转链接，也不想直接套一层第三方网页，所以把它改成了更接近 Codex 的工作台界面：左边是历史会话，中间是主要对话区，底部输入任务，模型连接状态也能直接看到。

![简屿内置的 AI Agent 工作台](./wechat-assets/04-agent.png)

目前界面已经可以连接配置好的 AI 模型，截图中使用的是 DeepSeek。接口层不是写死某一个模型，后续可以继续接入兼容的模型服务。API Key 只保存在本机配置中，不会写进项目源码，也不会跟着代码上传到 GitHub。

这个 Agent 入口最适合处理那些“事情不大，但来回切软件很烦”的任务，比如：

- 整理今天的工作内容；
- 把一段想法梳理成 PRD；
- 分析当前需求的风险；
- 根据资料生成待办或验收清单；
- 在一个固定窗口里继续多轮讨论。

单独看，每件事都能在别的 AI 软件里完成。简屿想解决的，是把这些入口和你日常打开 App、查看需求、刷一会儿视频的动作放到同一个地方。

## 我还塞进了一条完整的需求管理链路

顶部中间是 **需求管理**。

创建一个新需求后，简屿会为它自动建立独立文件夹，并按照阶段创建四个目录：

**需求 PRD → 原型文档 → 测试验收 → 上线。**

上传的文件会复制到当前需求对应的阶段目录中，而不是只留一个随时可能失效的路径。每个阶段可以分别管理文档，完成后推进到下一步，最后确认上线。

我做这个功能，是因为很多需求并不是没有文档，而是文档散得到处都是。PRD 在一个文件夹，原型在另一个工具，测试结果躺在聊天记录里，等上线时已经没人记得最初为什么做。

现在这套能力还比较轻量，但链路已经跑通。后面我希望继续把 Agent 接进来，让它不只是陪你聊天，而是能围绕同一个需求文件夹，协助整理 PRD、检查遗漏、生成验收清单和上线说明。

## 还有一些不抢戏，但每天能用到的东西

除了上面几个重点功能，简屿顶部还保留了监控提醒和音乐入口。

音乐页面可以在窗口内使用 Apple Music 网页版；监控提醒用来查看系统状态和提醒信息。整个面板点击外部区域会自动收起，平时只留在 Mac 顶部，不会一直挡着桌面。

它没有想把所有软件都替代掉。

我更希望它像一张贴在屏幕顶部的桌面抽屉：常用 App 在里面，需求资料在里面，AI 在里面，想喘口气时，抖音也在里面。需要的时候拉开，不需要的时候收起来。

## 为什么要把它放到 GitHub

因为这个项目本身，就是我一边使用、一边修改出来的。

我不是先写了一份特别完整的商业计划，再找团队开发。很多功能都来自真实使用时冒出来的问题：按钮被 Mac 摄像头区域挡住了，就重新排；抖音小窗不能滑，就换回桌面适配；关掉窗口还有声音，就继续把后台媒体暂停补上；AI 页面不好用，就照着自己熟悉的 Agent 工作台重做。

这种开发方式不一定优雅，但挺有生命力。

我也相信，真正好用的个人工具不一定要解决多宏大的问题。它只要每天替你少切几次窗口、少找几次文件，或者让工作间隙那几分钟更舒服一点，就已经有价值了。
